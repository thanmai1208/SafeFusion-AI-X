# SafeFusion AI X

**Predictive Explainable Collision Prevention for Autonomous Vehicles**

SafeFusion AI X is an AI-powered collision prevention system that analyzes driving videos in real time, detects pedestrians and vehicles, predicts collision risk using **Time-to-Collision (TTC)**, and provides explainable safety recommendations through an interactive dashboard.

## Features

* Real-time object detection using YOLO11
* Multi-object tracking with ByteTrack
* Time-to-Collision (TTC) prediction
* Collision risk classification
* Explainable AI recommendations
* Lane visualization
* Interactive Streamlit dashboard
* Downloadable processed video and analytics report

## Tech Stack

* Python
* YOLO11
* ByteTrack
* OpenCV
* Streamlit
* Plotly
* Pandas
* NumPy

## Installation

```bash
git clone https://github.com/thanmai1208/SafeFusion-AI-X.git
cd SafeFusion-AI-X
pip install -r requirements.txt
streamlit run app.py
```
